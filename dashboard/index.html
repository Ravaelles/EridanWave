EridanWave results dashboard

UMS survey rows are appended by scripts/ums-batch.sh to dashboard/data/history.jsonl (one JSON object per line). Melee rows use the same schema with "kind": "melee" and an enemy name. Serve this folder over HTTP so the page can load the data, e.g. cd dashboard && python3 -m http.server.

Direct file open blocks the data load (CORS). Either serve this folder (python3 -m http.server) or pick data/history.jsonl by hand:
